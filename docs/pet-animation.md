# 宠物显示与播放节奏

公开版本不携带个人宠物或第三方宠物图片。v0.7.2 之后的源码构建支持内置、本地自定义和本机已缓存的云端宠物，菜单栏与设置使用同一列表。默认选择 Codex 内置宠物，“系统图标”不再是可选项，旧偏好自动迁移。选择只影响岛，不改变 Codex 选择、云端记录或逐帧时钟。

## 本机素材与回退

CodexPetReader 读取所识别 Codex 应用的 app.asar，从至多八个已知命名成员解析静态字面量，不执行 JavaScript。只读取所选精灵图并检查成员边界及可用摘要；图片在解码前检查尺寸，随后缓存七组 96×104 帧。

自定义素材由独立来源发现，即使安装包解析失败也可使用：

| 来源 | 只读位置 | 限制 |
| --- | --- | --- |
| 本地自定义 | Codex 目录下 `pets/<slug>/pet.json` 和旧版 `avatars/<slug>/avatar.json` | 使用 `displayName`、`spriteVersionNumber`、`spritesheetPath`；稳定 ID 为 `custom:<slug>`；图片必须留在该宠物目录内 |
| 已缓存云端 | `.codex-global-state.json` 的当前账户宠物索引、`~/Library/Caches/Codex/Default/Cache/Cache_Data` | 仅列出已索引且存在匹配缓存的 `pet_` 宠物；从已有宠物列表响应读取名称；不联网补齐 |

云端图片被系统清除或尚未下载时，请在 Codex 查看该宠物，再使用岛的“重新同步宠物与时长”。支持已知 Chromium Simple Cache v5 格式、普通 / Brotli 宠物列表响应；其他缓存格式保守跳过，名称缺失显示“自定义宠物”。这不是与 Codex 账户的在线同步，不承诺完整云端目录或精确同步 Codex 当前选择。

预算：每个本地根目录最多 256 项，清单 64 KiB；全局状态 8 MiB、最多 128 个云端索引；缓存扫描最多 4096 个候选文件，每项只预读 24 字节头和最多 16 KiB 键。只读取已匹配宠物目录响应（至多 16 个，每个压缩体 1 MiB、解压 2 MiB）和所选图片（至多 8 个候选，单图 16 MiB，缓存文件上限 18 MiB）。普通文件检查、边界、键摘要与 CRC 校验失败时跳过；不解析其他缓存响应正文。精灵图必须为 1536×1872（v1）或 1536×2288（v2）。

损坏、不兼容或缓存暂时消失时保留已经解码的宠物和选择；首次加载失败时尝试可用的 Codex 内置宠物。全部不可用时仅显示静态备用图形和提示，列表不加入占位宠物。新选择按稳定 ID 保存，重启后重新读取本机素材。

测试帧在内存中生成匿名几何色块；不加载私人图片。个人素材不在 SwiftPM 资源或打包步骤中。

## 时序

启动、选择、Codex 启动通知及手动同步时尝试加载共享时长；未同步时使用内置兼容数值。PetTimingProfile 同时驱动动作、左右步态和休息基准。时长限制 1–60000ms，idle 倍数在乘法前验证，异常元数据抛错而不触发整数溢出。

本机 Codex 26.1013.40934 的历史观察基准为：

| 动作 | 行 | 帧数 | 单轮时长 |
| --- | --- | --- | --- |
| idle | 0 | 6 | 6600ms |
| running | 7 | 6 | 820ms |
| waiting | 6 | 6 | 1010ms |
| failed | 5 | 8 | 1220ms |
| review | 8 | 6 | 1030ms |
| walkingLeft / walkingRight | 2 / 1 | 8 | 1060ms |

上述是已观察版本的兼容回退，不保证未来版本不变。每次动作只播放一轮，再随机休息约 1–3 个 idle 周期。idle 可短距离漫步；状态切换读取实时位置，沿步态走回右侧。行走位移与帧索引共用 PetWalk 时间轴；任务取消后不提交旧终点。

缺少素材时的备用图形保持静态，所选有效精灵图才有逐帧动作。减少动态效果、暂停、隐藏或来源不可用时取消连续播放。轮廓动效与宠物帧调度独立。

## 验证边界

合成资源测试覆盖尺寸、透明度、不同帧、行边界、本地 / 云端发现、路径逃逸、特殊文件、缓存损坏、Brotli 名称与选择恢复。默认测试不读取个人图片。显式设置 `CODEX_ISLAND_TEST_APP` 可检查本机内置素材；同时设置 `CODEX_ISLAND_TEST_PET_HOME` 与 `CODEX_ISLAND_TEST_PET_CACHE` 可只读验证本机自定义素材和动画帧，不复制图片到仓库或发布包。这些检查不验证真实审批、所有系统 / 屏幕组合或长时性能，详见 [发布准备](release-readiness.md)。
