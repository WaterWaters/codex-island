# 首次使用与连接检查

本页描述 v0.8.1 Preview。旧版 v0.7.3 安装包尚不包含这里的新引导、分组连接页与 Mini 模式。

## 第一次打开

正常启动时，应用会显示三页使用引导，依次说明菜单栏入口与状态、本机连接、数据与可选权限。可随时跳过，也可以完成最后一页后开始使用。完成或跳过后不重复自动展示；在“设置 → 常规 → 重新查看使用引导…”中可以从第一页重看。

引导进度与外观偏好分开保存，恢复外观默认不会重新打开引导。引导不自动申请辅助功能权限、不启用实验审批识别、不发送聊天或执行审批。演示、预览图与诊断入口不自动展示引导，也不写入正式偏好。

## 找到设置

点击菜单栏的白色水猫图标，选择“设置…”。设置分为四页：

| 页签 | 内容 |
| --- | --- |
| 常规 | 显示 / 隐藏、标题隐私、语言、登录项、快捷键、重看引导 |
| 外观 | 完整 / Mini 显示模式、显示器、预设与即时预览、岛高度、宠物、颜色和动态效果 |
| 连接 | 连接状态、下一步、重新同步状态、复制脱敏诊断 |
| 实验功能 | 默认关闭的审批窗口识别与系统辅助功能入口 |

恢复默认、打开 Codex 和退出入口保留。新增偏好兼容旧版 v1 设置，不改变原有宠物、颜色或审批权限。恢复默认不会注册登录项；系统登录项按 macOS 的实际状态显示，独立于外观偏好。

## 常驻控制

- **Mini 模式**：从菜单栏直接切换，或到外观页选择显示模式。普通屏为 44 × 22 pt 顶部短胶囊，刘海屏按系统安全区自动取得宽高，沿外缘显示灯带；不提供机型写死尺寸。悬停查看状态，点击打开 Codex。Mini 隐藏文字与宠物，原有高度和宠物用于完整模式；默认升级仍保持完整模式。标题隐私同时适用于 Mini 的悬停和 VoiceOver。
- **标题隐私**：常规页开启“隐藏会话标题”后，岛、悬停和 VoiceOver 使用通用 Codex 标题。不会自动检测投屏；诊断始终不含标题。
- **语言**：默认跟随系统，也可选择 English / 简体中文 / 繁體中文 / 日本語，即时更新岛、菜单和设置。不会翻译用户标题、宠物专名或改变审批识别语言。切换不重置来源和待回答状态。
- **登录时启动**：主动开启后向 macOS 注册主应用；系统可能要求批准，界面保留实际状态与系统设置入口。失败不会显示为已开启。演示 / 诊断入口不注册。
- **快捷显隐**：主动开启 ⌃⌥⌘I。注册失败或冲突会显示提示，可关闭后重试；菜单栏入口始终可用，不需要辅助功能权限。
- **显示器**：默认使用系统主显示器，可固定到某个屏幕。断开时回落主屏，重接恢复；选择按屏幕 UUID 保存。
- **外观预设**：默认、静谧、高对比和自定义。选择预设即时预览；改色进入自定义。静谧与高对比使用静态效果；主动开启动画或改色会进入自定义。系统减少动态效果仍会暂停动画。

实际热插拔、全屏 / Space、锁屏及登录重启仍需对应硬件和系统交互验证，详见发布准备记录。

## 读懂连接页

| 提示 | 含义与下一步 |
| --- | --- |
| 未找到 Codex 应用 | 安装并打开 Codex，然后重新同步 |
| Codex 未运行 | 打开 Codex，应用会继续自动检查 |
| 尚未找到本机会话数据 | 在 Codex 打开本机会话；使用自定义目录时核对实际启动环境 |
| 本机来源暂不兼容 | 当前数据结构不受适配器支持，检查更新并复制脱敏诊断 |
| 暂时无法读取状态 | 自动重试；仍失败时重新同步或复制脱敏诊断 |
| 已连接 · 事件同步受限 | 数据库确认的基本活动可用，问答事件完整性尚未确认 |
| 已连接 · 正在追平事件 | 正在有界增量读取，不把不完整事件当作完整问答证据 |
| 已连接本机 Codex | 当前来源检查正常，仍受本机适配器范围约束 |
| 演示模式 / 显式外部状态 | 独立开发来源，不能作为真实 Codex 连接证据 |

“重新同步状态”清除来源游标与退避；它与“外观”页的宠物素材重同步分别工作。若 `CODEX_HOME` 配置无效，需要修正实际启动环境后重新打开应用，重试不会自动换到另一个目录。详细规则见 [本机来源](local-session-source.md)。

## 复制脱敏诊断

“复制脱敏诊断”只把版本、固定原因类别、来源类别及聚合同步健康值写入剪贴板。它不会上传或发送诊断，不包含会话标题、会话标识、用户路径、提示词、问题、答案或原始载荷。连接页会显示复制成功或失败。

基础状态不需要辅助功能权限。实验审批识别的权限范围、已验证能力和限制见 [安全与隐私](../SECURITY.md)。
