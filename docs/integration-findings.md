# 状态来源与验证记录

公开版记录更新于 2026-10-22。更早包含个人素材的开发笔记和预览仅保存在本机忽略目录，不参与公开仓库。

## 已确认

- 默认来源为本机 SQLite / 活动回合事件兼容适配，不是官方稳定状态 API。
- 桌面 IPC 研究曾取得初始化及订阅回执，但未取得可用业务快照。正式 GUI 不执行 Python 探针，也不凭握手成功宣称接通完整状态。
- 数据库连接只读，回合失败与命令失败区分；完成 / 中断进入 idle，不伪造未读。
- 已结束回合通过 CASE 跳过 latest-item 排序，避免空闲状态扫描历史工具项。
- 异步问题按受理回执及结构化用户回答配对。此前现场记录确认过问答等待与解除；本轮主要进行静态审查及自动化回归，不重演所有 GUI 场景。
- 公开构建无私人素材依赖；默认系统图标，本机 Codex 内置宠物按需只读加载。

## 本轮新增

修复异常时长溢出、显式 FIFO 阻塞及问答状态累积；合并重复刷新，并在图片解码前检查尺寸。安全静态审查没有确认可报告的越权漏洞或真实凭据。自动化、打包、性能数据和实际限制统一见 [发布准备记录](release-readiness.md)。
